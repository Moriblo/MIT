# dbot
Discord bot that answers like a pirate<br>

# .env 
Update the .env with your discord bot token and the key from OpenAI<br>
Token for the discord bot: https://discord.com/developers/applications<br>
Token for Groq: https://console.groq.com/keys<br>
Groq API: https://api.groq.com/openai/v1/chat/completions<br>

# hello bot
To start the bot, run the following commands:<br>
python discord_only.py (Just to deal with discord)<br>

# pirate bot 
run the following commands:<br>
pip install -r requirements.txt<br>
python mybot.py (Dealing with dicord and Groq)<br>

Set the following environment variables in your .env file:
- TOKEN
- GROQ_API_KEY
